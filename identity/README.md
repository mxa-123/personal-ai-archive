# identity/ — 个人身份档案

存放个人身份、职业、核心标签、人生目标等基础信息。
AI 读取后用于理解"你是谁"，避免在每次对话中重复询问。

## 文件清单
| 文件 | AI 标签 | 说明 |
|------|---------|------|
| profile.md | `AI-READONLY` | 身份核心信息（姓名、称呼、所在地等），只读 |
| career.md | `AI-EDITABLE` | 职业、核心标签、专业领域 |
| goals.md | `AI-EDITABLE` | 人生目标、价值观、长期愿景 |

## 使用约定
- 含 `AI-READONLY` 的文件：AI 只读取，**不修改、不删除**其中任何内容。
- 含 `AI-EDITABLE` 的文件：AI 可在完成任务后追加/更新内容，并**生成提交记录**。
- 所有占位符用 `{{...}}` 包裹，填写后删除花括号即可生效。
- 每个文件顶部 `<-- AI-META -->` 注释块供 AI 机器读取（标签 / 访问权限 / 更新日期）。
