# memory/ — 经验、决策与个人偏好沉淀

跨对话、跨 AI 平台复用的"记忆库"。
AI 完成任务后，应将新经验、偏好、重要决策写入对应文件并**生成提交记录**。

## 文件清单
| 文件 | AI 标签 | 说明 |
|------|---------|------|
| decisions.md | `AI-EDITABLE` | 重要决策与结论记录 |
| experiences.md | `AI-EDITABLE` | 踩坑经验、可复用方法 |
| preferences.md | `AI-EDITABLE` | 对话中沉淀的个人偏好 |

## 写入约定
- AI 只在文件末尾**追加**新条目，不覆盖历史内容。
- 每条记录带日期，便于追溯与回退。
- 敏感信息（手机号、密码、令牌）**禁止**写入本目录。
